## 使用提醒

1. **参考文档里的“当前 / 本轮”指写作当时**，不是现在的代码状态。
2. 涉及具体文件 / 行号 / 参数签名的描述可能已漂移；引用前用源码核对。
3. 三份现行文档与参考文档冲突时，以**现行文档 + 源码**为准，并顺手修正参考文档里的过时提示。
4. 新增参考文档统一放在本目录，并在上表登记（主题 / 时间 / 现在怎么用）。
