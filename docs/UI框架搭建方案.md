### 本轮实现目标

本轮的主要目标是使用navigation实现基本的UI框架，不必实现所有的UI细节。先实现一个登录界面，本登录界面不需要过度打磨UI，只要实现基本功能就行，因为访问服务器的数据和数据持久化已经实现，所以实现登录界面并不复杂，如果涉及了新的认证功能，请新建一个文件专门用于用户的登录注册认证。

第一个页面先展示登录界面，只有登录注册成功之后才能显示真正的应用界面，登录界面的内容如下，两个输入框分别输入用户名和密码，有登录与注册两个按钮，点击注册跳转用户注册界面，登录页面还需要写一个占位的图片组件，用于后期打磨UI的时候加入。登录与注册页面相互独立，注册之后实现自动登录。

```
品牌图标
抑郁症智能辅助评估
面向临床与研究场景
这个是我们的登录界面的设计，在这三个信息图标之下就是输入框和登录注册按钮
```

主页面使用navigation路由，下面有五个按钮，分别是工作台，素材库，历史报告，统计，我的。目前只需要实现页面跳转，具体的页面内容全部占位。

本轮修改的页面的统一UI风格如下

```
页面背景：#F4F8FB
卡片背景：#FFFFFF
主色：#0D9488
辅助蓝：#0284C7
正文：#1E3A5F
次要文字：#64748B

- 卡片圆角控制在 8vp 左右
- 少使用大面积渐变
- 重要分数使用较大字号
- 页面标题 22vp 左右
- 正文不小于 14vp
- 不要同时使用太多颜色
- 加载时显示骨架屏
- 网络失败时提供重试按钮
- 空数据时提供下一步操作
```

所有的页面代码全部在page文件夹中，每个页面都要新建文件夹，如果需要使用，请通过引用的方式使用。

每个页面需要标注自己要接受的参数，也就是说直接传入参数就能展示页面，这样避免了在页面内部写代码和引用变量，使代码可读性更高、
