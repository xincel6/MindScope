## 3. 交互链路（本轮唯一主链路）

```
工作台 [选择素材]
   └─ push('mediaPicker')                     ← Navigation 入栈，返回键回工作台
        用户选中图片/视频
        └─ MediaApi.upload(file)  → media_id
              └─ AppStore.startAnalysis(media_id)   ← WS 立刻开始跑
                    └─ push('analysisDetail', {mediaId, name, type})
                         ├─ 详情页显示：素材名 / 进度 / 实时分数（图表区留白）
                         └─ 返回（PageHeader 返回键 或 系统返回）
                              └─ 工作台「当前任务」卡片出现（WS 在 AppStore 上继续跑）
                                   └─ 点击该卡片 → 再进详情页
```

- 页签切换仍用 `replacePathByName`（栈深恒 1），二级页用 `pushPathByName` → 系统返回键天然可用。
- 详情页返回**不停止**分析（D8 的前提）；`AnalysisStateHolder` 已在 AppStore 单例上，无需改造。
- 「查看全部」→ 切到 `MainTab.reports` 页签。

## 5. 卡片点击涟漪（可行性：可行）

实现（每个卡片约 10 行，只在 `RippleCard` 内实现一次）：

1. `Stack` 包住卡片内容；
2. `onTouch(TouchType.Down)` 取触点**相对组件**的坐标 `touches[0].x / y`；
3. 在该点放一个圆（半径 = 卡片对角线长，放大后必然盖满整卡）；
4. `animateTo`：`scale 0 → 1`（300ms，`Curve.EaseOut`）+ `opacity 0.18 → 0`；
5. 卡片外层 `.clip(true)` + `borderRadius(8)` → 涟漪被圆角裁剪，不溢出。

**可行原因**：只用「单元素 scale + opacity」，走渲染合成层，不触发布局重排；`animateTo` 是 ArkUI 原生能力，无第三方依赖。

**坑与对策**：

- 涟漪挂 `TouchType.Down`，导航动作仍放 `onClick` → 不干扰滚动/长按；
- 卡内 `Button`（如「选择素材」）会自己吃掉点击 → 按钮单独挂同一涟漪，或让按钮区不冒泡；
- 纯白背景（D7）下涟漪必须用**主色 12% 透明**（`#1F0D9488`）才看得见。

### 8.3 构建方式（本机踩坑记录）

本机**没有** `hvigorw` 包装器，且命令行构建有两个坑，已封装成脚本 `harmony/scripts/build.sh`：

```bash
bash harmony/scripts/build.sh          # → entry/build/default/outputs/default/entry-default-unsigned.hap
```

1. 用户目录必须用 **`HVIGOR_USER_HOME`**（`HVIGOR_HOME` 无效）；
2. `PackageHap` 需要 `java`，要把 DevEco 自带 JBR 加进 PATH（否则 `spawn java ENOENT`）；
3. 在受限沙箱里会 `es2abc spawn EPERM`，换非受限方式执行即可（脚本已说明）。
