## 六、已知雷区（全部实测踩过，别再试错）

### 6.1 工程路径必须是纯 ASCII —— 这是硬约束

- hvigor 对工程路径做**字符白名单校验**，路径含中文直接拒绝，**连编译都不会开始**：
  ```
  00306003 Specification Limit Violation
  Invalid project path. Current path does not match: C:\...\基于 MSSTformer...\MindScope\harmony
  BUILD FAILED in 1 s 885 ms
  ```
  （实测：把工程放回原中文目录，1.9 秒即失败；官方错误码文档同时列有 `00306002 工程路径不能包含中文字符`。）
- 官方文档：`developer.huawei.com` →「规格错误码」→ 00306002 / 00306003。
- **因此：绝对不要把工程移回中文目录**，也不要把中文目录当工程根。当前路径 `C:\Users\tiaotiao\Desktop\MindScope\harmony` 可正常构建。

### 6.2 三方库版本：ohpm 源上没有 mpchart 4.x

- ohpm 官方源（ohpm.openharmony.cn）上 `@ohos/mpchart` **最高只有 3.0.30**；gitee master 的 `4.0.0-rc.0` **未发布**。
- 一旦写进不存在的版本号，`ohpm install` 直接失败（`00617101 NOTFOUND package '@ohos/mpchart@...'`），**工程同步整体崩掉**。
- **改依赖版本前，先在源上确认该版本存在。**

### 6.3 ArkTS 语法：build() / @Builder 体内不能声明局部变量

- 在 `build()` 里写 `const stats: StatsModel | null = this.app.statsSummary;`（带不带类型标注都一样）会触发：
  ```
  00305015 Rollup Error: Unexpected token   ← 位置指向容器收尾的那个右花括号，极具误导性
  10905210 ArkTS Compiler Error: In an '@Entry' decorated component, the 'build' method
           can have only one root node, which must be a container component   ← 这是连带假象
  ```
- **正确写法**：取值逻辑放进 `@Computed` getter，或在调用处用 `as` 收窄：
  ```ts
  } else {
    this.buildContent(this.app.statsSummary as StatsModel)
  }
  ```
- 相关已验证结论：**UI 元素或属性链后面跟分号是合法的**（实测通过），不必刻意删除；`if / else if / else` 链、`@Builder` 带参调用、`@Computed` getter 在 `@ComponentV2` 里都正常。

### 6.4 本 SDK（API 23）装饰器写法

- `@Monitor` 是**方法装饰器且必须带监听路径字符串**：`@Monitor('buckets')` + 无参回调；
  `@Monitor()` 空参、以及从 `@kit.ArkUI` import `IMonitor` 的方式**均已不存在**。

### 6.5 mpchart 3.0.30 的真实 API（与网上文章 / 4.x 文档有出入，已逐条对照源码核实）

| 事项 | 正确写法 |
|---|---|
| 图表组件形态 | `PieChart` / `LineChart` 是 V1 `@Component` **struct**，`model` 是普通成员 → 只能在 `build()` 里 `PieChart({ model: this.model })`，**不能 `new`** |
| 折线数据点 | **没有 `LineEntry` 类**，用基类 `EntryOhos(x, y)` |
| 多色设置 | `dataSet.setColorsByArr(number[])`（不是 `setColors`） |
| 描述文案 | `Description.setText()` 返回 **void**，不能链式调用；且默认文本是 `"Description Label"`，**必须显式置空**，否则会显示在图上 |
| 重新渲染 | 改数据后**必须手动 `this.model.invalidate()`** |
| 阈值线累积 | 重复 render 时 LimitLine 会累积 → 先 `yAxis.removeAllLimitLines()` 再 `addLimitLine()` |
| 阈值线标签位置 | `LimitLabelPosition` 只有 `LEFT_TOP / LEFT_BOTTOM / RIGHT_TOP / RIGHT_BOTTOM`（**没有** `X_LEFT_TOP`） |
| 渐变色填充 | `dataSet.setGradientFillColor(JArrayList<ChartColorStop>)`，`ChartColorStop = [颜色串, 位置0~1]`，颜色串用 8 位 hex（末两位是 alpha） |
| LineData 构造 | 只收 `ILineDataSet[]` 或 `JArrayList<ILineDataSet>`：`new LineData([dataSet])`，**不收单个 dataSet** |
| 颜色格式 | 颜色 API 收 **number**（0xAARRGGBB），不收 `'#RRGGBB'` 字符串 → 组件内有 `toArgb()` 转换 |
| 实现源码位置 | `harmony/oh_modules/.ohpm/@ohos+mpchart@3.0.30/oh_modules/@ohos/mpchart/src/main/ets/`（可随时对照） |
