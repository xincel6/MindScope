## 2. ★ 关键发现：离场动画从实现起就从未播放过

**现象**：真机连拍页签切换，连续多帧**整页全空**（只剩灰底 + 页签栏）。
**排除法**：把节拍临时放慢 4 倍（`cardMs 960 / stepMs 440`）后连拍 5 帧（覆盖 1.75s，而离场在慢放下长 2280ms）——**依然全是空白**。采样点问题被排除。

**根因**：`RevealCard.playOut()` 是在 `@Monitor('transit.exitClock')` 里**同步**调 `animateTo` 的。而 `@Monitor` 是在 MainPage 修改 `exitClock` 的**同一次状态更新中同步回调**的 —— 此刻调 `animateTo`，动画被这次更新吃掉，属性**直接跳到终值**：卡片瞬移到屏外、透明度瞬变 0，整页"啪"一下消失。

**修复**：把 `playOut()` 推迟一帧（`setTimeout(..., 16)`）再启动。
**验证**：同一慢放参数下，推迟后立刻抓到"页头已推出左边界、卡片还在半途"的中间帧；恢复真实节拍后连拍依次为 完整页 → 位移中 → 换页后，**75KB 的空白帧彻底消失**。

## 3. 一个必须记录的取舍：离场"整页滑出" ≠ "两页同屏交叉"

仓库里 `docs/鸿蒙页签横移动画-可行性评估与实测记录.md` 记录过"轨道容器"方案（新旧两页同屏横移，`t1.jpeg` 证明可行），但它与**每页卡片的错峰入场**互斥 —— 页面常驻后不再重新挂载，`RevealCard` 的入场动画就永远不会播。
用户上一轮明确要了错峰入场，故本轮**保留错峰**，把离场做成"整页同速滑出、滑到屏外那一刻才换页"。

## 6. 遗留 / 已知

1. `CardTransit.scaleOut` 现已无引用（离场不再缩放），保留未删 —— 属公开转场令牌，删除应单独立项。
2. 状态胶囊运行态底色用 `cardPressTint`（对比度约 1.03:1，B 代理曾提示可能读不出）。真机实测**可读**：靠状态圆点 + 主色文字撑住轮廓，无需改 `fillSoft`。
3. 统计页三小卡/两图卡因改走 `RippleCard` 基座，多出一条 1px `divider` 描边（与工作台卡片一致）。
4. 「两页同屏交叉」横移仍未实现（与错峰入场互斥，见 §3）。
5. 登录/注册页仍未做目视验收（需登出，会清本机登录态）。
