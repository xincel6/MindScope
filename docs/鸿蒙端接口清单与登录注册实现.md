> 结论先行：
> 1. **`src/api/` 那三个文件不是接口定义，只是 Web 前端顺手写的一层薄封装**（其中 `http.ts` 一个接口都没有）。真正的接口面是后端 `backend/routers/` 的 **5 个 router = 12 个 REST + 1 个 WebSocket + 1 个静态目录**，权威清单是 `http://<host>:8000/openapi.json`（FastAPI 自动生成，`main.py:23` 没有关掉）。
> 2. 登录注册的后端契约非常简单：**注册成功直接返回 token（即注册即登录）**，客户端不存用户对象、只存 token；**没有 logout 接口**，登出 = 本地删 token。ArkTS 侧要写的是 `HttpClient` + `AuthApi` + `TokenStore` + `AuthStore` + 一个双模式登录页。

## 一、真实接口面：14 条，不是 3 个文件

### 1.1 全量清单（以 `backend/routers/*.py` 为准）

| # | 方法 | 路径 | 鉴权 | 请求 | 响应 | 前端 `src/api/` 是否封装 |
|---|---|---|---|---|---|---|
| 1 | POST | `/api/auth/register` | — | `{username, password, email?}` | `{access_token, token_type:"bearer"}` | ✔ `auth.ts` |
| 2 | POST | `/api/auth/login` | — | `{username, password}` | 同上 | ✔ `auth.ts` |
| 3 | GET | `/api/auth/me` | Bearer | — | `{id, username, email, created_at:"YYYY-MM-DD"}` | ✔ `auth.ts` |
| 4 | GET | `/api/media/list` | Bearer | — | `{items:[MediaItemOut]}` | ✔ `index.ts` |
| 5 | DELETE | `/api/media/{media_id}` | Bearer | — | `{ok:true}` | ✔ `index.ts` |
| 6 | POST | `/api/analyze` | Bearer | `{id}` | `{task_id}` ⚠ **空壳** | ✔ `index.ts` |
| 7 | POST | `/api/analyze/face` | Bearer | `{image_base64}` | `{bdi_score, inference_time_ms, heatmap_data}` | ✔ `index.ts` |
| 8 | POST | `/api/upload/image` | Bearer | multipart，字段名 `file` | `{id, name, type, url}` ⚠ 只有 4 个字段 | ✘ **裸调**：`stores/dashboard.ts:177` |
| 9 | GET | `/api/report/{media_id}` | Bearer | ⚠ path 是 **int** | `[ReportOut]` | ✘ 未封装 |
| 10 | GET | `/api/reports` | Bearer | `severity, media_type, page, limit` | `{items, total}` | ✔ `index.ts` |
| 11 | GET | `/api/stats` | Bearer | — | `StatsOut` | ✔ `index.ts` |
| 12 | WS | `/ws/analysis` | `?token=<JWT>` | `{"id"}` / `{"type":"cancel"}` / `{"type":"ping"}` | `status` / frame / `vlm_analysis` / `done` / `error` | `useWebSocket.ts` |
| 13 | GET | `/health` | — | — | `{status:"ok"}` | ✘ |
| 14 | GET | `/media/{filename}` | **无鉴权** | — | 静态文件（视频/图片流） | `<img>/<video>` 直接引用 |

**所以"只有三个文件"是不成立的**：`api/` 只覆盖了 12 条 REST 里的 9 条，上传和报告列表压根不在里面；而且它连 WS 都不含（WS 在 `composables/useWebSocket.ts`）。

### 1.2 三处必须提前知道的"不完整"

1. **`/api/upload/image` 的响应不是完整 `MediaItem`**，只有 `id/name/type/url` 四个字段。Web 端在下游手动补齐（`dashboard.ts:183-191`：`thumbnail_url: ''`、`duration: undefined`、`created_at` 用本地日期）。ArkTS 侧同样要补，且 `created_at` 必须按后端的 `%Y-%m-%d` 格式自己拼，别用 `new Date().toISOString()` 带时区偏移的写法。
2. **`/api/analyze` 是空壳**（`media.py:94-95` 注释原文："Analysis is triggered via WebSocket"），只回显 `task_id`。别指望它触发分析。
3. **后端没有的接口**（别按 Web UI 的想象去实现）：没有登出接口、没有改密码、没有删除报告、没有分页拉媒体列表、没有用户注册后的邮箱验证。登出纯粹是客户端行为（Web 端就是 `localStorage.removeItem`）。

### 1.3 鉴权细节（`auth_utils.py` + `config.py`）

- JWT：HS256，载荷 `{sub:"<user_id>", username, exp}`，**有效期 7 天**（`JWT_EXPIRE_MINUTES = 60*24*7`）。
- **没有 refresh 接口** → 过期后只能重新登录，所以 401 必须全局处理成"踢回登录页"。
- REST 用 `Authorization: Bearer <token>`；**WS 只能把 token 放进 query 参数**（`ws.py:33`）。
- 无效 token 访问 WS：服务端 `close(code=1008, reason="Unauthorized")` → 客户端应识别 1008 并直接登出。

## 二、登录注册：后端真实契约

### 2.1 请求/响应

```
POST /api/auth/register
  body: {"username":"郭书萍","password":"123456","email":null}
  200 → {"access_token":"eyJ...","token_type":"bearer"}      ← 注册即登录

POST /api/auth/login
  body: {"username":"guoshiping","password":"123456"}
  200 → {"access_token":"eyJ...","token_type":"bearer"}

GET  /api/auth/me      (Authorization: Bearer <token>)
  200 → {"id":1,"username":"guoshiping","email":null,"created_at":"2026-06-17"}
```

### 2.2 错误码表（★ 客户端要一一对应到提示文案）

| HTTP | `detail` | 触发条件 | 出处 |
|---|---|---|---|
| 400 | 用户名需 3–32 位，仅支持字母、数字、下划线或中文 | 用户名不匹配 `^[a-zA-Z0-9_\u4e00-\u9fa5]{3,32}$` | `auth.py:23` |
| 400 | 密码至少 6 位 | 注册时密码 < 6 | `auth.py:33` |
| 400 | 用户名已存在 | 注册重名 | `auth.py:37` |
| 400 | 邮箱已被注册 | 注册邮箱重复 | `auth.py:43` |
| 401 | 用户名或密码错误 | 登录失败（**不区分用户不存在/密码错**） | `auth.py:64` |
| 403 | 账号已禁用 | `is_active=False` | `auth.py:66` |
| 422 | `detail` 是**数组** | 字段缺失/类型不对（Pydantic 兜底） | FastAPI 默认 |

**关键点：`detail` 可能是字符串（HTTPException）也可能是数组（422）。** Web 端 `parseApiError` 两种情况都兜住了；ArkTS 没有 `any`，必须显式判断，不能直接 `as {detail: string}`——否则 422 时会把数组当字符串用，弹出一堆 `[object Object]`。

**另一个关键点：注册和登录的成功响应里没有用户信息**，想要用户名/注册日期必须再调一次 `/api/auth/me`。Web 端就是这么做的（`stores/auth.ts:29-30` → `setToken` 后 `loadUser()`），HarmonyOS 端照做。

### 2.3 客户端本地校验（照抄后端规则，省一次往返）

- 用户名：`^[a-zA-Z0-9_\u4e00-\u9fa5]{3,32}$`（注意 ArkTS **不能用正则字面量**，要 `new RegExp(...)`）
- 密码：长度 ≥ 6
- 登录页按钮在本地校验不过时就置灰，别让用户白等一次网络往返

### 3.1 `ApiConfig.ets`

```ts
import { preferences } from '@kit.ArkData';

export class ApiConfig {
  public static host: string = '192.168.1.100';   // ★ 后端局域网 IP，联调时改这里
  public static readonly port: number = 8000;
  public static token: string = '';

  public static baseUrl(): string {
    return `http://${ApiConfig.host}:${ApiConfig.port}`;
  }
  /** WS 的 token 只能走 query 参数（backend/routers/ws.py:33） */
  public static wsUrl(): string {
    return `ws://${ApiConfig.host}:${ApiConfig.port}/ws/analysis?token=${encodeURIComponent(ApiConfig.token)}`;
  }
  /** 把 host 也持久化：答辩现场改地址不用重装 App */
  public static async load(ctx: Context): Promise<void> {
    const p = await preferences.getPreferences(ctx, 'depression_app');
    ApiConfig.host = await p.get('host', ApiConfig.host) as string;
  }
  public static async saveHost(ctx: Context, host: string): Promise<void> {
    ApiConfig.host = host;
    const p = await preferences.getPreferences(ctx, 'depression_app');
    await p.put('host', host);
    await p.flush();
  }
}
```

### 3.2 `HttpClient.ets`（所有 REST 的唯一出口）

```ts
import { http } from '@kit.NetworkKit';
import { ApiConfig } from '../common/ApiConfig';
import { TokenStore } from '../store/TokenStore';

/** detail 可能是 string（HTTPException）也可能是数组（422），用 Object 接住 */
interface ErrBody { detail?: Object; }

export class ApiError extends Error {
  public code: number = 0;
  constructor(code: number, message: string) {
    super(message);
    this.code = code;
  }
}

export class HttpClient {
  static get<T>(path: string): Promise<T> { return HttpClient.core<T>(path, http.RequestMethod.GET, null); }
  static del<T>(path: string): Promise<T> { return HttpClient.core<T>(path, http.RequestMethod.DELETE, null); }
  static post<T>(path: string, body: string | null): Promise<T> {
    return HttpClient.core<T>(path, http.RequestMethod.POST, body);
  }

  private static async core<T>(path: string, method: http.RequestMethod, body: string | null): Promise<T> {
    const req = http.createHttp();
    try {
      // ★ 显式声明 Record<string,string>：不要用对象字面量喂 Object 类型字段
      const header: Record<string, string> = { 'Content-Type': 'application/json' };
      const token: string = TokenStore.get();
      if (token.length > 0) { header['Authorization'] = 'Bearer ' + token; }

      const options: http.HttpRequestOptions = {
        method: method,
        header: header,
        extraData: body === null ? undefined : body,
        expectDataType: http.HttpDataType.STRING,
        connectTimeout: 10000,
        readTimeout: 30000
      };
      const resp = await req.request(ApiConfig.baseUrl() + path, options);
      const text: string = typeof resp.result === 'string' ? resp.result as string : '';

      if (resp.responseCode >= 200 && resp.responseCode < 300) {
        return (text.length > 0 ? JSON.parse(text) : null) as T;
      }
      // 与 Web 端 http.ts:22 行为一致：401 全局登出；登录/注册接口自身除外
      if (resp.responseCode === 401 && !path.startsWith('/api/auth/')) {
        TokenStore.clear();
      }
      throw new ApiError(resp.responseCode, HttpClient.parseDetail(text, resp.responseCode));
    } finally {
      req.destroy();   // ★ 必须销毁，否则连接句柄会泄漏
    }
  }

  private static parseDetail(text: string, code: number): string {
    if (text.length === 0) { return `HTTP ${code}`; }
    try {
      const body = JSON.parse(text) as ErrBody;
      const d: Object | undefined = body.detail;
      if (typeof d === 'string') { return d as string; }         // 400 / 401 / 403
      if (d !== undefined) { return JSON.stringify(d); }         // 422 的数组形态兜底
    } catch (e) {
      // 忽略，走 fallback
    }
    return `HTTP ${code}`;
  }
}
```

### 3.3 `AuthApi.ets`

```ts
import { HttpClient } from './HttpClient';

export interface TokenOut { access_token: string; token_type: string; }
export interface AuthUser { id: number; username: string; email: string | null; created_at: string; }

/** 请求体用带参构造的 class：ArkTS 不允许对象字面量初始化带参构造的类 */
class LoginBody {
  public username: string;
  public password: string;
  constructor(u: string, p: string) { this.username = u; this.password = p; }
}
class RegisterBody {
  public username: string;
  public password: string;
  public email: string | null;
  constructor(u: string, p: string, e: string | null) { this.username = u; this.password = p; this.email = e; }
}

export class AuthApi {
  static login(username: string, password: string): Promise<TokenOut> {
    const body = JSON.stringify(new LoginBody(username, password));
    return HttpClient.post<TokenOut>('/api/auth/login', body);
  }

  static register(username: string, password: string, email: string): Promise<TokenOut> {
    // 后端 email 为 Optional：空串要发 null（Web 端 auth.ts:33 同样处理）
    const body = JSON.stringify(new RegisterBody(username, password, email.length > 0 ? email : null));
    return HttpClient.post<TokenOut>('/api/auth/register', body);
  }

  static me(): Promise<AuthUser> {
    return HttpClient.get<AuthUser>('/api/auth/me');
  }
}
```

### 3.4 `TokenStore.ets`

```ts
import { preferences } from '@kit.ArkData';

export class TokenStore {
  private static store: preferences.Preferences | null = null;
  private static token: string = '';

  static async init(ctx: Context): Promise<void> {
    TokenStore.store = await preferences.getPreferences(ctx, 'depression_app');
    TokenStore.token = await TokenStore.store.get('token', '') as string;
  }
  static get(): string { return TokenStore.token; }

  static async save(token: string): Promise<void> {
    TokenStore.token = token;
    const s = TokenStore.store;
    if (s !== null) { await s.put('token', token); await s.flush(); }
  }
  static async clear(): Promise<void> { await TokenStore.save(''); }
}
```

### 3.5 `AuthStore.ets`

```ts
@ObservedV2
export class AuthStore {
  @Trace token: string = '';
  @Trace username: string = '';
  @Trace email: string = '';
  @Trace createdAt: string = '';
  @Trace loading: boolean = false;

  private static inst: AuthStore | null = null;
  static get(): AuthStore {
    if (AuthStore.inst === null) { AuthStore.inst = new AuthStore(); }
    return AuthStore.inst;
  }

  isLogin(): boolean { return this.token.length > 0; }

  async login(username: string, password: string): Promise<void> {
    this.loading = true;
    try {
      const t: TokenOut = await AuthApi.login(username, password);
      await this.applyToken(t.access_token);
    } finally {
      this.loading = false;
    }
  }

  async register(username: string, password: string, email: string): Promise<void> {
    this.loading = true;
    try {
      const t: TokenOut = await AuthApi.register(username, password, email);
      await this.applyToken(t.access_token);   // 注册即登录，与 Web 端一致
    } finally {
      this.loading = false;
    }
  }

  /** App 冷启动：有 token 就拉 /me 验证（等价于 Web 的 initFromStorage + 路由守卫） */
  async restore(): Promise<boolean> {
    this.token = TokenStore.get();
    if (this.token.length === 0) { return false; }
    return await this.loadMe();
  }

  private async applyToken(token: string): Promise<void> {
    this.token = token;
    await TokenStore.save(token);
    ApiConfig.token = token;          // 供 WS 拼 query 参数
    await this.loadMe();
  }

  private async loadMe(): Promise<boolean> {
    try {
      const u: AuthUser = await AuthApi.me();
      this.username = u.username;
      this.email = u.email ?? '';
      this.createdAt = u.created_at;
      return true;
    } catch (e) {
      await this.logout();            // /me 失败（401/网络）→ 当作未登录，与 Web 端一致
      return false;
    }
  }

  /** 后端没有 logout 接口，登出 = 本地清 token */
  async logout(): Promise<void> {
    this.token = ''; this.username = ''; this.email = ''; this.createdAt = '';
    ApiConfig.token = '';
    await TokenStore.clear();
  }
}
```

### 3.6 `LoginPage.ets`（登录/注册双模式）

```ts
import { promptAction } from '@kit.ArkUI';
import { AuthStore } from '../store/AuthStore';
import { ApiError } from '../network/HttpClient';

@Entry
@Component
struct LoginPage {
  @State isRegister: boolean = false;
  @State username: string = '';
  @State password: string = '';
  @State email: string = '';
  @State errorMsg: string = '';
  // ★ ArkTS 不支持正则字面量，用 new RegExp
  private usernameRe: RegExp = new RegExp('^[a-zA-Z0-9_\\u4e00-\\u9fa5]{3,32}$');

  private validate(): string {
    if (!this.usernameRe.test(this.username)) {
      return '用户名需 3–32 位，仅支持字母、数字、下划线或中文';
    }
    if (this.password.length < 6) { return '密码至少 6 位'; }
    return '';
  }

  async submit(): Promise<void> {
    const local = this.validate();
    if (local.length > 0) { this.errorMsg = local; return; }
    this.errorMsg = '';
    const store = AuthStore.get();
    try {
      if (this.isRegister) {
        await store.register(this.username, this.password, this.email);
      } else {
        await store.login(this.username, this.password);
      }
      promptAction.showToast({ message: '欢迎，' + store.username });
      // 用 replaceUrl：登录页不留在栈里，避免返回键回到登录页
      this.getUIContext().getRouter().replaceUrl({ url: 'pages/IndexPage' });
    } catch (e) {
      const err = e as ApiError;
      this.errorMsg = err.message;        // 直接就是后端 detail 文案
    }
  }

  build() {
    Column({ space: 16 }) {
      Text(this.isRegister ? '注册账号' : '登录').fontSize(24).fontWeight(FontWeight.Bold)
      TextInput({ placeholder: '用户名' })
        .onChange((v: string) => { this.username = v; })
        .maxLength(32)
      TextInput({ placeholder: '密码' })
        .type(InputType.Password)
        .onChange((v: string) => { this.password = v; })
      if (this.isRegister) {
        TextInput({ placeholder: '邮箱（可选）' })
          .onChange((v: string) => { this.email = v; })
      }
      if (this.errorMsg.length > 0) {
        Text(this.errorMsg).fontColor('#f3b2bd').fontSize(13)
      }
      Button(AuthStore.get().loading ? '请稍候…' : (this.isRegister ? '注册' : '登录'))
        .enabled(!AuthStore.get().loading)
        .width('100%')
        .onClick(() => { this.submit(); })
      Text(this.isRegister ? '已有账号？去登录' : '没有账号？去注册')
        .fontColor('#0284c7')
        .onClick(() => { this.isRegister = !this.isRegister; this.errorMsg = ''; })
    }
    .padding(24)
  }
}
```

## 四、联调 Checklist

1. 后端**必须**用局域网 IP 起：`serve_all.py` 默认 `HOST=127.0.0.1`，手机连不上。改成 `HOST=0.0.0.0` 或本机 IP。

3. 先用 `POST /api/auth/register` 在后端 `depression.db` 里造一个用户，再用鸿蒙端登录，排除"注册"这一步的干扰。
4. 用 `curl` 或 `/docs` 的 Swagger 页面确认后端活着：`GET http://<ip>:8000/health`。
5. 登录成功后立刻验证 WS：拿 token 直接连 `ws://<ip>:8000/ws/analysis?token=<token>`，连上就说明鉴权链路通了（不发 `{"id"}` 会在 15s 后收到 `No media id received`，**这是预期的**）。

## 五、2026-10-18 增量：患者命名、上传者与登录链路

### 5.1 端上新增的两个调用（后端尚未跟上）

| 方法 | 路径 | 端上实现 | 后端现状 |
|---|---|---|---|
| POST | `/api/upload/image?patient=<name>` | `MediaApi.uploadImageWithPatient` | ❌ 不接收 `patient` 查询参数，患者名只存端上 |
| PUT | `/api/media/{id}/patient` | `MediaApi.updatePatient`（body `{patient}`） | ❌ 路由不存在，重命名会失败 |

**端上当前行为**：

- 上传：后端不接收 `patient`，但端上会把入参补进本地镜像（`commitUpload`），列表立刻可见；
- 重命名：**先调 `PUT`，成功后才写本地 RDB / 内存**；当前接口不存在，所以返回失败文案
  （`ActionResultModel.ok = false`），本机数据保持不变；

### 5.2 `uploader_name`：远程已返回，旧数据为空

2026-10-18 直接核对远程 `/openapi.json`：`ReportListItem` **已包含 `uploader_name`**（`string | null`）。
本地源码同样具备：

### 5.3 登录 / 注册链路的实际实现（与第三章样例的差异）
